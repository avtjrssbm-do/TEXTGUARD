Введение
Цель данного проекта — создание локальной сети предприятия с двумя подсетями, подключением к интернету и настройкой основных сервисов.
В ходе работы рассматриваются:
•	Принципы IP-адресации и подсетей
•	Типы топологий сетей и их применение
•	Конфигурация ПК, серверов, коммутаторов и маршрутизатора
•	Настройка базовых сервисов (DNS, Web)
•	Проверка работоспособности сети и подключение к интернету
Проект позволяет понять, как строятся локальные сети, как обеспечивается взаимодействие между различными подсетями и как предоставляются базовые сервисы для пользователей.
 
Теоретическая часть
1. Основы сетевых технологий
Локальная сеть (LAN) — это объединение устройств (ПК, серверов, принтеров и других сетевых устройств) внутри ограниченной территории для обмена данными и совместного использования ресурсов.
Основные компоненты сети:
•	ПК — конечные устройства пользователей, обеспечивают доступ к ресурсам сети
•	Коммутатор (Switch) — устройство канального уровня (L2), соединяет ПК внутри подсети, передаёт кадры
•	Маршрутизатор (Router) — устройство сетевого уровня (L3), соединяет различные подсети и обеспечивает маршрутизацию
 
2. Типы топологий сетей
Существуют различные топологии сетей:
1.	Шина (Bus) — устройства соединены одной линией передачи. Применяется редко из-за проблем с масштабированием и отказоустойчивостью.
2.	Звезда (Star) — все устройства подключены к центральному коммутатору или хабу. Высокая отказоустойчивость: при выходе одного устройства остальные продолжают работу.
3.	Кольцо (Ring) — устройства соединены последовательно, формируя замкнутый круг. Поток данных идёт по одному направлению.
4.	Дерево (Tree) — комбинация нескольких звезд с иерархической структурой.
5.	Гибридная топология (Hybrid) — сочетание нескольких типов топологий для повышения надежности и функциональности.
Моя сеть:
•	Внутри каждой подсети — звезда (ПК + сервер подключены к коммутатору)
•	Подсети объединены через маршрутизатор
•	Роутер подключён к интернету
→ Следовательно, сеть является гибридной топологией
 
3. IP-адресация и подсети
IP-адрес — уникальный идентификатор устройства в сети.
Основные параметры:
•	IP-адрес: уникальный идентификатор, пример — 192.168.1.2
•	Маска подсети: определяет количество устройств в подсети, пример /24 или 255.255.255.0
•	Шлюз по умолчанию: IP маршрутизатора для выхода за пределы подсети
Пример настройки подсетей:
Подсеть	Диапазон IP	Шлюз
VLAN10	192.168.10.0/24	192.168.10.1
VLAN20	192.168.20.0/24	192.168.20.1
 
4. Роль маршрутизаторов и коммутаторов
•	Коммутатор (Switch):
o	Работает на уровне L2
o	Передаёт кадры внутри одной подсети
o	Обеспечивает высокую скорость и безопасность локального трафика
•	Маршрутизатор (Router):
o	Работает на уровне L3
o	Передаёт пакеты между подсетями
o	Обеспечивает подключение к внешним сетям (интернет)
 
5. Основные сервисы сети предприятия
1.	DNS (Domain Name System) — преобразует доменные имена в IP-адреса. Например, pc0.company.local → 192.168.10.2
2.	HTTP (Web-сервер) — позволяет пользователям получить доступ к веб-страницам
3.	FTP (File Transfer Protocol) — обеспечивает передачу файлов между клиентом и сервером
4.	DHCP (Dynamic Host Configuration Protocol) — автоматически выдаёт IP-адреса, маску подсети и шлюз
 
Практическая часть
1. Постановка задачи
•	Создать сеть предприятия с двумя подсетями (каждая по два ПК)
•	Объединить подсети через маршрутизатор
•	Настроить IP-адресацию
•	Проверить связь внутри и между подсетями
•	Настроить основные сервисы: Web/DNS, FTP, DHCP
 
2. Схема сети
Размещение устройств:
1.	4 ПК: PC0, PC1, PC2, PC3
2.	2 коммутатора: Switch0, Switch1
3.	1 роутер: Router0
4.	1 сервер: Web/DNS Server (PC0)
5.	Облако Интернет: Internet
Соединение кабелями:
•	ПК → Свитч (Copper Straight-Through)
•	Сервер → Свитч
•	Свитч → Роутер
•	Роутер → Интернет (Copper Straight-Through)

4. Настройка ПК и серверов
•	Desktop → IP Configuration → ввести IP, Маску, Шлюз
•	Для ПК, использующих DNS: указать IP Web/DNS Server 192.168.10.2
•	Включение сервисов на серверах:
Web/DNS Server: HTTP и DNS → добавить запись pc0.company.local → 192.168.10.
